# ROADMAP

## Phase 0 — Foundation
- Establish repository contracts and source-of-truth docs
- Confirm business identity and known contact/location data
- Define information architecture and content-integrity rules
- Add continuous `/continue` workflow

## Phase 1 — Research and content model
- Research Tile Mart's public presence and local competitors
- Build verified/unverified business-fact inventory
- Define SEO keyword clusters based on user intent, not keyword stuffing
- Define product/category content schema
- Identify missing owner assets and facts

## Phase 2 — Design system and shell
- Initialize Next.js + TypeScript + Tailwind
- Create responsive layout system
- Implement header/navigation/footer
- Establish typography, spacing, surfaces, borders and interaction rules
- Integrate supplied logo without distorting it

## Phase 3 — Core pages
- Home
- Tiles hub
- Sanitary hub
- About
- Showroom
- Contact
- Reusable category/product presentation components

## Phase 4 — Conversion and local SEO
- WhatsApp deep links with useful prefilled enquiry text
- Phone and showroom CTAs
- Metadata and canonical URLs
- Local-business structured data using only verified facts
- Sitemap and robots
- Internal linking and location relevance
- Social links

## Phase 5 — Quality
- Responsive checks across common widths
- Accessibility audit
- SEO audit
- Performance audit
- Broken-link and content-integrity audit
- Lint, typecheck, build and automated smoke tests

## Phase 6 — Launch readiness
- Production environment documentation
- Search Console checklist
- Analytics integration instructions
- Domain/deployment checklist
- Final owner-only missing-data checklist

## Definition of done
The project is complete only when all non-owner-blocked tasks in `TASKS.md` are done, the production build passes, core routes are smoke-tested, no known high-severity accessibility/SEO defects remain, and all published business claims are either verified or clearly non-factual marketing language.
