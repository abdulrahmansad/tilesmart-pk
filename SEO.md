# Tile Mart SEO Strategy

## Objective

Make Tile Mart easy to discover for high-intent tile and sanitary-ware searches in Peshawar while keeping every business claim accurate.

## Page targeting

| Page | Primary intent |
| --- | --- |
| `/` | Tile Mart Peshawar, tiles and sanitary ware Peshawar |
| `/tiles` | tiles in Peshawar, tile shop Peshawar |
| `/tiles/floor-tiles` | floor tiles Peshawar |
| `/tiles/wall-tiles` | wall tiles Peshawar |
| `/tiles/bathroom-tiles` | bathroom tiles Peshawar |
| `/tiles/kitchen-tiles` | kitchen tiles Peshawar |
| `/sanitary-ware` | sanitary ware Peshawar, wash basin Peshawar, bathroom sets Peshawar |
| `/showroom` | Tile Mart Karkhano Market, Tile Mart address, directions |
| `/contact` | Tile Mart phone, Tile Mart WhatsApp |
| `/about` | Tile Mart Peshawar business entity context |

## Technical SEO already built

- Unique title/description on core pages
- Canonical paths
- Dynamic sitemap
- robots metadata route
- LocalBusiness/HomeGoodsStore JSON-LD
- Postal address, coordinates, phone, sameAs social profiles and map link in structured data
- Open Graph and Twitter metadata
- Generated social preview image
- Semantic page headings and internal links
- Mobile-first responsive layout
- Accessible skip link and keyboard focus states

## Launch requirements

1. Set `NEXT_PUBLIC_SITE_URL` to the final HTTPS domain.
2. Deploy the site and verify every sitemap URL resolves with status 200.
3. Add the final website URL to the Google Business Profile.
4. Verify the domain in Google Search Console.
5. Submit `/sitemap.xml` in Search Console.
6. Ensure Google Business Profile name/address/phone match the website exactly.
7. Keep business hours synchronized once the owner confirms them.
8. Add real showroom/product photography with descriptive alt text when available.
9. Add real brands/categories only after they are verified.
10. Do not generate thin suburb pages or repetitive keyword pages purely for ranking.

## Content expansion after launch

Only add content that answers a useful customer question. Priority ideas:

- How to measure a room for tiles
- Floor tile vs wall tile: what changes?
- Bathroom tile planning checklist
- Choosing tile size for small and large rooms
- What to send on WhatsApp when asking for tile availability

These can build topical relevance without inventing inventory.
